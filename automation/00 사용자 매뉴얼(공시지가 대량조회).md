# 공시지가 대량조회 — 사용자 매뉴얼

> 버전 2026.10.04 · Windows 10/11 · 무료(MIT License) · 비공식 개인 제작 도구

토지 목록(엑셀)을 올리면 필지별 **개별공시지가**를 국토교통부 브이월드에서 일괄 조회해 화면에 집계하고, 감사조서용 엑셀로 내려받는 도구입니다.
인터넷 연결과 **본인 명의 브이월드 인증키**가 필요합니다. **설치할 프로그램은 없습니다** — 폴더를 그대로 복사해 두면 됩니다(윈도우에 기본 내장된 PowerShell로 동작).

---

## 1. 준비물

| 준비물 | 확인 방법 |
|---|---|
| Windows PC + 인터넷 | — |
| 이 폴더(압축을 푼 것) | 맨 위에 `01 공시지가_조회_실행.cmd`(실행기) · `02 공시지가조회_업로드양식.xlsx` · 이 매뉴얼, `automation` 폴더 안에 화면(`공시지가_대량조회_배포.html`) · 도우미(`공시지가_도우미.ps1`) · 키 파일 양식(`vworld_key.txt.example`). **반드시 압축을 푼 뒤 실행** |
| 브이월드 인증키 | 아래 2장에서 발급(무료, 5분) |

> 왜 도우미가 필요한가: 브이월드 API는 브라우저가 직접 부르지 못하게 되어 있어(교차출처 차단), 작은 **로컬 도우미**(PowerShell 스크립트)가 대신 호출합니다. 도우미는 내 PC 안(127.0.0.1)에서만 동작하고 외부에서 접속할 수 없으며, 윈도우 10/11에 기본 내장된 PowerShell로 실행되므로 아무것도 설치하지 않습니다.

## 2. 브이월드 인증키 발급 (각자 본인 계정으로)

1. [www.vworld.kr](https://www.vworld.kr) 접속 → 회원가입 → 로그인.
2. 상단 메뉴 **오픈API → 인증키 발급** (또는 마이포털 → 나의 오픈API → 인증키 발급).
3. 이용약관 동의 체크 후 아래처럼 입력합니다.

| 항목 | 입력값 |
|---|---|
| 서비스명 | `공시지가 조회` |
| 서비스분류 | `국토관리` |
| 서비스유형 | **웹사이트** |
| 서비스URL | `http://localhost` ← **반드시 localhost** (실제 웹사이트가 아니어도 됩니다) |
| 서비스설명 | 개요: 보유·검토 대상 토지의 개별공시지가를 필지별로 조회하는 개인용 로컬 도구(내 PC에서만 실행) / 서비스대상: 본인(업무 참고용) / 목적: 토지 공시지가 확인 및 검토자료 작성 — 본인 상황에 맞게 고쳐 써도 됩니다 |
| 활용API | **2D데이터 API** ✔, **지오코더 API** ✔ (둘 다 체크. 앞은 공시지가·토지대장, 뒤는 도로명→지번 변환) |
| 사용기관 | `민간` + 소속(회사명 또는 개인) |
| 활용사례공개 | 체크 안 해도 됨 |

4. [발급] → **인증키 관리** 화면에 `XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX` 형태의 키가 표시됩니다. 발급일·**만료일**(발급일 + 6개월)도 함께 보입니다.

### 인증키 파일 만들기
1. `automation` 폴더의 `vworld_key.txt.example`을 **복사**해서 이름을 `vworld_key.txt`로 바꿉니다.
2. 메모장으로 열어 아래처럼 3줄만 남깁니다(`#`으로 시작하는 줄은 설명이라 있어도 됩니다).

```
XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX    ← 1줄: 인증키 (앞뒤 공백 없이)
localhost                               ← 2줄: 도메인 (그대로)
2027-03-17                              ← 3줄: 만료일 (인증키 관리 화면의 만료일, 화면에 D-day 경고용)
```

3. 저장(Ctrl+S). 파일 인코딩은 메모장 기본(UTF-8)이면 됩니다.

> 이 파일은 **본인 PC에만** 둡니다. 다른 사람에게 도구를 줄 때는 키 파일을 빼고 주고, 받는 사람이 같은 방법으로 발급합니다(약관상 키는 발급자 책임, 사용량도 발급자 계정에 합산).

### 갱신
- 개발키는 **6개월** 뒤 만료됩니다. 만료 **전에** 마이포털 → 나의 오픈API → **인증키 관리 → 연장신청**(3회까지 가능). 연장하면 키 값은 그대로이고 만료일만 늘어납니다 → `vworld_key.txt` 3줄 날짜만 고칩니다.
- 만료가 지나면 재발급(2장 반복) 후 `vworld_key.txt` 1줄과 3줄을 바꿉니다.
- 화면 상단 알약에 "만료 D-30" 이하가 뜨면 연장할 때입니다.

## 3. 실행

1. `01 공시지가_조회_실행.cmd` **더블클릭**. 도우미가 숨은 창으로 뜨고 브라우저에 화면이 열립니다(도우미가 이미 떠 있으면 화면만 엽니다).
2. 화면 오른쪽 위 알약 확인:
   - 🟢 **도우미 연결됨 · 인증키 있음 · 만료 YYYY-MM-DD** → 정상
   - 🔴 **도우미 꺼짐** → `.cmd`를 다시 실행. 그래도 안 되면 5장 참조
   - 🔴 **인증키 없음** → `automation\vworld_key.txt` 확인(파일명·위치·1줄 키)
   - 🟠 **모의모드** → 가짜 데이터 상태. 도우미를 `--mock` 없이 실행해야 함(일반 사용자는 볼 일 없음)

## 4. 사용 순서

### ① 조회대상 입력
- **[📥 업로드 양식 다운로드]**로 양식(`토지목록` 시트: 자산번호·소재지·면적(㎡)·비고)을 받아 채운 뒤, 파일을 점선 상자에 끌어놓습니다. 열 이름이 달라도 됩니다 — 업로드 후 **주소 열·식별자 열·면적 열·비고 열**을 고를 수 있습니다(자동 추정됨).
- 또는 오른쪽 칸에 주소를 한 줄에 하나씩 붙여넣습니다(`식별자<탭>주소` 또는 `식별자,주소`면 첫 칸이 식별자).
- **조회 연도**: `2026,2025`처럼 쉼표로 여러 해. 첫 연도가 집계 기준입니다.
- [리스트에 추가]. 이미 리스트가 있으면 뒤에 붙습니다.

주소는 **지번주소**(시도 시군구 읍면동 번지, 예 `서울특별시 강남구 역삼동 737`, `... 동부리 산 12-3`)가 기본입니다. 도로명주소는 ②에서 변환합니다.

### ② 리스트 확인·수기 가감
- 표의 주소·식별자·면적·비고는 **셀을 클릭해 바로 수정**. 주소를 고치면 PNU가 자동 재인식됩니다. Enter로 아래 행 이동.
- [+ 행 추가] / 체크 후 [선택 삭제] / [주소 전체 재인식].
- 인식 배지: **인식**(정상) · **모호**(같은 동·리명이 여러 곳 — 시군구 확인) · **확인필요**(법정동을 못 찾음 — 도로명·행정동명·오타).
- **도로명주소**가 확인필요로 남으면 행의 [지번변환] 또는 툴바 [🧭 도로명→지번 변환(미인식 행)]. 변환되면 배지가 **변환**으로 바뀌고 원래 도로명은 엑셀 `원주소(도로명)` 열에 남습니다. 한 건물이 여러 필지면 대표 필지 하나만 나오니 대장과 대조하세요.
- [🔎 공시지가 일괄조회] → 진행률 표시, [중지] 가능. 옵션 "지목·대장면적도 조회"(기본 켬), "조회완료 행 건너뛰기"(재조회 시 끔).
- 조회 배지: **조회완료** · **결과없음**(그 해 미공시이거나 PNU가 실제 필지가 아님) · **오류**(도우미·키·통신 문제, 마우스를 올리면 사유).

### ③ 집계·내보내기
- 상단 통계(총 필지·인식·조회완료), **연도별 합계 토지가액**, **시군구별 합계**(기준연도).
- 토지가액 = 공시지가(원/㎡) × 면적. 면적은 **입력한 면적 우선**, 비우면 **토지대장 면적**(API)을 쓰고 `면적출처`에 표시합니다.
- [📊 엑셀 내보내기] → `조회결과`(필지별 전 항목) · `요약`(연도별·시군구별 합계) · `조회로그`(어느 API를 언제 호출해 무슨 응답을 받았는지 — 감사 증빙). [CSV]도 가능.
- [세션 저장]/[세션 불러오기]: 작업 중간 상태를 JSON으로 보관·복원(다음 날 이어서 할 때).

## 5. 문제 해결

| 증상 | 조치 |
|---|---|
| 알약이 "도우미 꺼짐" | `.cmd` 재실행(도우미가 뜨는 데 3초쯤 걸림 — 화면의 [다시 확인]). 계속 꺼져 있으면 회사 보안정책이 PowerShell 스크립트 실행을 막는 경우이니 전산 담당에게 `automation\공시지가_도우미.ps1` 실행 허용을 요청 |
| "인증키 없음" | `automation\vworld_key.txt` 파일명이 정확한지(`.txt.example`이 아닌지), 1줄에 키만 있는지 |
| 조회 배지 **오류**, 사유에 `INVALID_KEY` / `등록되지 않은 인증키` | 키 오타 또는 **만료**. 인증키 관리 화면에서 연장/재발급 후 파일 수정(도우미는 매 요청 때 파일을 다시 읽으므로 재시작 불필요) |
| 오류 사유에 `NO_KEY`/`NETWORK` | 인터넷 연결·사내 프록시 확인 |
| **결과없음**이 많음 | 조회 연도가 미공시 연도(당해 공시는 보통 5월 말 이후)이거나 주소 인식이 틀린 경우. 인식 배지와 시군구·읍면동을 확인 |
| 도로명 변환이 실패 | 상세주소(동·호수)·괄호를 빼고 `시도 시군구 도로명 건물번호`만 남겨 재시도 |
| 키 파일을 고쳤는데 반영 안 됨 | 도우미는 요청 때마다 파일을 읽으므로 즉시 반영. 안 되면 파일명(`vworld_key.txt`)·위치(`automation` 폴더) 확인 |

## 6. 결과 해석 시 주의
- 개별공시지가는 **매년 1월 1일 기준**(5월 말 공시). 분할·신규 필지는 7월 1일 기준 값이 따로 있을 수 있어 `기준월`을 표시합니다.
- `표준지` 열이 `Y`면 표준지공시지가 대상 필지입니다.
- `법정동 대조`가 **확인**이면 주소 인식 결과와 API가 돌려준 법정동명이 다른 것입니다(모호 매칭 의심).
- 공식 열람화면과 대조하려면 행의 [알리미] 버튼(주소·PNU가 복사되고 부동산공시가격알리미가 열림).
- 이 도구의 값은 브이월드 API 응답이며, 감사조서에는 `조회로그` 시트(조회일시·API·응답코드)를 함께 보관하세요.
